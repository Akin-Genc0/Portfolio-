# Akin Genc | Portfolio

A responsive personal portfolio for Akin Genc, a Software Engineer. It presents professional experience, selected GitHub work, current technical interests, and a printable CV.

## Features

- Responsive dashboard-style portfolio built with the Next.js App Router
- Live GitHub profile, repository, and public activity data, refreshed hourly
- Selected project links, including live and npm package links where available
- CV page at `/cv`
- Graceful fallbacks when GitHub data is unavailable

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- GitHub REST API
