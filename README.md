# Akin Genc | Portfolio

A responsive personal portfolio. It presents professional experience, selected GitHub work, current technical interests, and a printable CV.

<img width="1900" height="2300" alt="https-akingenc dev- (2)" src="https://github.com/user-attachments/assets/a21b2b9b-69d3-44e1-82b8-73e6f3d80f84" />


## Features

- Responsive dashboard-style portfolio built with the Next.js App Router
- Live GitHub profile, repository, and public activity data, refreshed hourly
- Selected project links, including live and npm package links where available
- CV page at `/cv`
- Graceful fallbacks when GitHub data is unavailable

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- GitHub REST API
